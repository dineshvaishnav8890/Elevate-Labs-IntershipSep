# Task 4 - Version-Controlled DevOps Project with Git

## 📌 Project Overview

This project demonstrates Git and GitHub best practices as part of the DevOps Internship Task 4.

The objective is to understand how Git can be used to manage a DevOps project using version control, branching, commits, pull requests, tags, and documentation.

## 🎯 Objectives

- Initialize a Git repository
- Create and manage Git branches
- Follow a feature development workflow
- Create meaningful commits
- Push the project to GitHub
- Use Pull Requests for merging
- Configure `.gitignore`
- Create Git tags
- Document the complete Git workflow
- Understand merge conflicts and their resolution

## 🛠️ Tools Used

- Git
- GitHub
- Linux / WSL Ubuntu
- Bash
